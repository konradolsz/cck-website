
# Project

Creative Code Kortrijk (CCK) is a creative coding club in Kortrijk, Belgium.

The website is for people who are interested in creative coding and want to learn more about the club.

The website contains workshops, foundations and information about the team.

# Stack & constraints

- The website is built with Astro.
- The project uses Astro content collections.
- Workshops, Foundations and Team are separate collections.
- Content is stored in Markdown files.
- Collection schemas are defined in `src/content.config.ts`.
- The project does not use a CSS framework.
